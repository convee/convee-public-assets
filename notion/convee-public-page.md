# Convee public tools and reusable templates

A small public guide for five focused tools. Each link points to a real utility and each template is safe to copy and adapt.

## Tools

- [Winter Arc Contract](https://winterarccontract.com/?utm_source=notion&utm_medium=referral&utm_campaign=public-guide) — choose rules, dates, and a printable 90-day contract.
- [Challenge Contract](https://challengecontract.com/?utm_source=notion&utm_medium=referral&utm_campaign=public-guide) — create a dated challenge plan and tracker.
- [Listvaro Amazon Listing Audit](https://listvaro.com/?utm_source=notion&utm_medium=referral&utm_campaign=public-guide) — review listing evidence before making edits.
- [Chaoschemy](https://chaoschemy.com/?utm_source=notion&utm_medium=referral&utm_campaign=public-guide) — play short browser games without a download.
- [AngleCue](https://anglecue.app/?utm_source=notion&utm_medium=referral&utm_campaign=public-guide) — turn buyer questions into page improvement ideas.

## Public templates

The [public templates repository](https://github.com/convee/convee-public-assets) contains a 90-day contract, a challenge plan, a listing audit checklist, a browser game guide, and a buyer hesitation worksheet. It contains no customer data, credentials, or production implementation.

## Privacy

The AngleCue Page Notes extension stores captured notes in the browser's local extension storage. It does not send page data to a remote server. Do not paste credentials or private customer information into any public template.

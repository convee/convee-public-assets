# 90-day Winter Arc contract template

![Winter Arc contract planning illustration](../assets/winter-arc-contract.png)

A plain-text contract you can print or adapt for a 90-day Winter Arc. The date is intentionally left open: choose a start date that fits your life, then use the [Winter Arc Contract generator](https://winterarccontract.com/?utm_source=github&utm_medium=referral&utm_campaign=winter-arc-template) to calculate the exact end date and create a printable copy.

## Template

```text
WINTER ARC CONTRACT

Name: ______________________________
Start date: ____________  End date: ____________

My reason for this arc:
____________________________________________________________

Daily rules (write rules that can be answered yes or no):
[ ] 1. ______________________________________________________
[ ] 2. ______________________________________________________
[ ] 3. ______________________________________________________
[ ] 4. ______________________________________________________
[ ] 5. ______________________________________________________

My minimum version for a difficult day:
____________________________________________________________

If I miss a day, I will:
____________________________________________________________

Signature: _________________________  Date: ________________
```

Keep the rules measurable and small enough to follow on an ordinary day. The generator also includes a tracker and export options.

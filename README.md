# Convee public templates

Small, reusable templates published alongside the free Convee tools. Each folder is a practical starting point that can be copied, adapted, or used to understand the format accepted by the corresponding product.

- [Winter Arc contract template](./winter-arc-contract/README.md) — a printable 90-day habit contract format.
- [Challenge contract template](./challenge-contract/README.md) — a date-based challenge plan and tracker format.
- [Listvaro listing audit checklist](./listvaro-listing-audit/README.md) — a transparent checklist for reviewing an Amazon listing before editing it.

The live tools remain the source of truth for generated dates, calculations, and account features:

- [Winter Arc Contract](https://winterarccontract.com/?utm_source=github&utm_medium=referral&utm_campaign=public-assets)
- [Challenge Contract](https://challengecontract.com/?utm_source=github&utm_medium=referral&utm_campaign=public-assets)
- [Listvaro Amazon Listing Audit](https://listvaro.com/?utm_source=github&utm_medium=referral&utm_campaign=public-assets)

These files contain no product secrets, credentials, customer data, or production implementation.

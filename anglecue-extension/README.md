# AngleCue Page Notes extension

A small Manifest V3 Chrome extension that captures the active page title, URL, first heading, and visible price metadata, then lets the user record a buyer hesitation locally. It never sends page data to a server and uses `activeTab` only after the user clicks the capture button.

## Load locally

1. Open `chrome://extensions`.
2. Turn on Developer mode.
3. Choose **Load unpacked** and select this folder.
4. Open a product page, click the extension, then click **Capture current page**.

The Chrome Web Store listing still needs a store icon, privacy disclosure, screenshots, and the developer registration/publishing step.

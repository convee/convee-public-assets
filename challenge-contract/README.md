# Date-based challenge contract template

![Challenge contract calendar illustration](../assets/challenge-contract.png)

Use this format to plan any fixed-length challenge: fitness, reading, study, saving, digital detox, or a personal experiment. For exact end dates and a printable calendar, open the [Challenge Contract builder](https://challengecontract.com/?utm_source=github&utm_medium=referral&utm_campaign=challenge-template).

## Template

```text
CHALLENGE CONTRACT

Challenge name: ______________________________
Start date: ____________  Length: ______ days
End date: ____________

What counts as a completed day?
____________________________________________________________

Daily checklist:
[ ] _________________________________________________________
[ ] _________________________________________________________
[ ] _________________________________________________________

What I will do when the day is difficult:
____________________________________________________________

Weekly check-in day: ______________
What I will review: _________________________________________

Signature: _________________________  Date: ________________
```

Write the completion rule before the challenge starts. That keeps the tracker useful when motivation changes.

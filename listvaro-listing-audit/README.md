# Amazon listing audit checklist

![Listing audit checklist illustration](../assets/listvaro-listing-audit.png)

A transparent pre-edit checklist for an Amazon product detail page. It is deliberately platform-agnostic: verify the current marketplace rules before publishing any change. For an automated report with issue evidence and prioritization, open [Listvaro Amazon Listing Audit](https://listvaro.com/?utm_source=github&utm_medium=referral&utm_campaign=listing-audit-checklist).

## Checklist

| Area | Check | Evidence to record |
|---|---|---|
| Title | Product, primary use, and distinguishing attribute are clear | Current title and character count |
| Images | Main image is clear at thumbnail size; secondary images explain use | Image URLs and missing information |
| Bullets | Each bullet communicates one benefit or proof point | Bullet number and suggested revision |
| Description | Claims are specific and supported | Claim, source, and risk |
| Search terms | Terms match the product and buyer language | Term, location, and duplication |
| Variations | Parent and child relationships are accurate | ASIN, variation theme, and mismatch |
| Compliance | Medical, environmental, comparative, and guarantee claims are reviewed | Claim text and evidence status |
| Offer | Price, availability, and delivery promise are current | Timestamp and marketplace |

Do not paste credentials, private customer data, or unpublished supplier information into an audit request. Treat the checklist as a review aid; marketplace policy and the seller's evidence remain authoritative.
